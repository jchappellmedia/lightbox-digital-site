Traffic, bounce rate & clicks

Checking…

The tag on your site writes data to Google Analytics. To read it back onto this page, one small script has to ask Analytics for the numbers. The easiest way is Apps Script — it runs inside your own Google account, so there is nothing to install and no Cloud project to set up.

  1. Open script.google.com and start a new project.
  2. Paste in Code.gs, then fill in your Property ID (Analytics ▸ Admin ▸ Property settings) and any random key you like.
  3. Deploy ▸ New deployment ▸ Web app — run as Me, access Anyone. Approve the Analytics permission when asked.
  4. Paste the deployment URL below with your key on the end: …/exec?key=YOURKEY

Alternative — connect straight from this browser instead

Skips Apps Script, but needs a Google Cloud OAuth client and a sign-in each time. Create one at console.cloud.google.com (enable the Google Analytics Data API, then Credentials ▸ OAuth client ID ▸ Web application, with https://lightbox-digital.com as an authorised origin).
